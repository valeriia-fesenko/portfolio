# Valeriia Fesenko — Portfolio

One-page portfolio / résumé site for Valeriia Fesenko, Data Analyst based in
Dresden, Germany. Built with plain HTML/CSS/JS — no build step, no
dependencies besides Google Fonts (loaded via CDN).

**Live demo:** add your GitHub Pages URL here once deployed.

## Files

- `index.html` — the whole site (HTML + CSS + JS in one file). The
  profile photo is embedded directly in the code as base64, so this
  single file is the entire site — no other assets needed.

## Deploy with GitHub Pages (5 minutes)

1. Create a new repository on GitHub.
   - Name it **`valeriia-fesenko.github.io`** if you want the site at
     `https://valeriia-fesenko.github.io` directly, **or**
   - Name it anything else (e.g. `portfolio`) and the site will be at
     `https://valeriia-fesenko.github.io/portfolio`.
2. Add the file to the repo root:
   - Open the repo → **Add file → Upload files** → drag in `index.html`
     → **Commit changes**.
3. Go to **Settings → Pages** in the repository.
4. Under **Build and deployment**: Source = `Deploy from a branch`,
   Branch = `main`, Folder = `/ (root)`. Click **Save**.
5. Wait 1–2 minutes, then open the URL GitHub shows on that same page.
